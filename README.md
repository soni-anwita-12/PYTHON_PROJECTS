# 🌦️ Python Weather App

## About the Project
The Python Weather App is a beginner-friendly project that retrieves real-time weather information for different cities using the WeatherAPI.com API.

Users can enter a city name and get important weather details, including temperature, weather conditions, humidity, and wind speed.

## Features
- **City Search:** Search for weather information by entering a city name.
- **Temperature:** Displays the current temperature in Celsius.
- **Weather Conditions:** Provides information about sunny, cloudy, rainy, and other conditions.
- **Humidity:** Displays the current humidity percentage.
- **Wind Speed:** Shows the current wind speed.
- **Error Handling:** Handles invalid city names and API-related errors.

## Technologies Used
- **Python:** Main programming language.
- **Requests:** For sending HTTP requests.
- **WeatherAPI.com:** For retrieving weather information.
- **JSON:** For processing API responses.

## Installation and Usage

**1. Clone the repository**
```bash
git clone YOUR_REPOSITORY_URL
```

**2. Install the required library**
```bash
pip install requests
```

**3. Get your API key**

Create a free account at [WeatherAPI.com](https://www.weatherapi.com/) and obtain your API key.

**4. Add your API key**

```python
API_KEY = "YOUR_API_KEY"
```

**5. Run the application**
```bash
python weather.py
```

Enter a city name to view its current weather information.
